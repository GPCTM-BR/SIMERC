There's a bug in `gsim_python.py`!
The `try/except` block is supposed to determine whether the flow
is single-phase (if it's two-phase, `fluid.speed_sound()` raises an error).
But that’s not what happens!
It works perfectly with the HEOS backend, but with BICUBIC, for some reason, the `try` block
doesn't raise an error; it calculates something instead (from what I gathered in some GitHub discussions,
it only treats it as two-phase if all interpolation points are on the same side of the dome,
or something like that—to be honest, I didn't fully understand it). Anyway, BICUBIC causes issues.
I already fixed this in the Cython code, but I didn't touch it here since I'm not using that code anymore.
I left a screenshot in this folder showing the difference between HEOS and BICUBIC.
After the fix, everything matched up perfectly! :)
I posted some photos showing the BICUBIC before and after. You can see that after the fix, it matches the HEOS!
